L1 – Binance (Crypto Market Data)

*Objetivo*
Capturar sinais brutos do mercado cripto que representem:
- Preço agregado
- Liquidez
- Alavancagem
- Stress de mercado
- Fluxo direcional

Os ativos escolhidos não são “bets”, mas sensores de estado do mercado.

Todos os ativos são configurados via parameters.yml.
